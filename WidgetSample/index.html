  6. 06. 대시보드 상단 바 (TopBarProxy)+ / 공유 / 도움말 메뉴에 항목 넣기 (setContent / addContent), 하위 메뉴, MenuItem 배지(countBadge), activate / deactivate / empty / die. 3DDashboard 에서만 동작
  7. 07. 3D / 2D 미리 보기 (3DPlay)DS/3DPlayHelper/3DPlayHelper 로 physicalid 의 3D / 2D 미리 보기와 닫기, TransientWidget 으로 3DPlay 앱(X3DPLAW_AP) 열기. 3DDashboard 에서만 동작
  8. 08. 성숙도 변경, 개정 (lifecycle)getStateGraph → 갈 수 있는 state → promote / demote, dslc getNextStates / changeState, revise/major, ownership/transfer, OOTB 성숙도 창 / 작은 성숙도 표시 / 개정 창 / 소유자 변경 창 (MaturityCmd, ReviseCmd), Lifecycle.Modification 알림. 3DDashboard 에서만 동작
